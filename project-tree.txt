## Principes et conventions

* Fichiers composants en `PascalCase.jsx`. Dossiers en `kebab-case` ou `lowerCamel` au choix. Je recommande `kebab-case` pour dossiers.
* Styles locaux en `*.module.css` pour éviter les collisions.
* Répartir en `components/` (UI + layout + effets) et `features/` (fonctionnalités, pages).
* Points d'entrée clairs: `src/main.jsx` et `src/router/index.jsx`.
* Garder `services/api/*` pour les appels réseau.
* Utiliser `index.js` dans dossiers quand on veut des exports par défaut (barrel files).

## Commandes `git` proposées (préservent l'historique)

Exemple pour un fichier :

```bash
git checkout -b refactor/restructure-project
git mv src/index.js src/main.jsx
git mv src/router.jsx src/router/index.jsx
# ... répéter git mv pour chaque fichier mentionné ci-dessus
git commit -m "chore: restructure project folders and rename files"
```

Pour renommer un dossier complet en conservant l'historique :

```bash
git mv src/components/Admin src/features/admin
git mv src/components/buttons src/components/ui
# etc
```

## Mise à jour des imports (exemples)

Utiliser `git grep` + `sed` ou un outil JS pour corriger les chemins. Exemple macOS/Linux (GNU `sed` peut varier) :

```bash
# recherche des fichiers qui importent l'ancien chemin
git grep -l "components/buttons/goBackButton" | xargs sed -i '' 's@components/buttons/goBackButton@components/ui/GoBackButton/GoBackButton@g'

# ou une commande portable avec perl
git grep -l "components/buttons/goBackButton" | xargs perl -pi -e 's|components/buttons/goBackButton|components/ui/GoBackButton/GoBackButton|g'
```
