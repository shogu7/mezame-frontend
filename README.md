## Audience

Designed for passionate manhwa readers who want to organize and showcase their collections.

---

## Features

### For Users
- **Reading Status:** Assign a status to a manhwa (Reading / Finished / Dropped).  
- **Library Management:** Add manhwa to your library, update the current chapter, give ratings, and filter or sort by status, rating, or progress.  
- **Public Profiles:** Visitors can see the user's pseudonym, avatar, biography, total finished/dropped/ongoing works, manhwa list with progress, status, notes, and profile creation date.

### In Development / Coming Soon
- **Community Contribution:** Users can propose new manhwa to be added to the database.  
- **Web Extension:** Detects the manhwa you are reading in your browser and allows you to push the data to your profile with a single button click.  
- **Mobile Application:** Mezame will be available on mobile with a simple interface, allowing users to track their reading progress anywhere, anytime.

### For Admins
- Manage users and permissions.  
- Validate or add manhwa suggested by the community.  
- Edit or delete content, including user accounts.
